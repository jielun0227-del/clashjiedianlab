# 机场订阅链接怎么导入

购买机场套餐后，官网控制台都会提供一条专属的**订阅链接 (Subscription URL)**。以下是各大客户端的导入步骤：

---

## 一、 Clash Verge Rev / Mihomo Party (Windows / macOS)
1. 登录机场官网后台，找到 **“一键导入 Clash”** 按钮点击自动唤醒客户端；
2. 若无法唤醒，点击 **“复制订阅链接”**；
3. 打开 Clash Verge，点击左侧 **`配置 (Profiles)`** 选项卡；
4. 将复制的链接粘贴到顶部 URL 输入框中，点击 **`导入 (Import)`**；
5. 右键下载好的配置选中并点击 **`启用 (Use)`** 即可。

---

## 二、 Shadowrocket (小火箭 - iOS)
1. 打开 Shadowrocket，点击右上角的 **`+`** 号；
2. 类型选择 **`Subscribe`** (订阅)；
3. 在 `URL` 栏中粘贴机场订阅链接，备注填写机场名称；
4. 点击右上角 **`保存`**；
5. 在主界面下拉页面，客户端会自动加载所有节点。

---

## 三、 Sing-box / Surfboard (Android / iOS)
1. 打开客户端，进入 **`Profiles / 节点`** 管理；
2. 点击新增，类型选择 **`HTTP 订阅 / Remote`**；
3. 粘贴订阅链接并更新保存。
