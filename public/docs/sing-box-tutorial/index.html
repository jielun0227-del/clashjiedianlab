配置结构

Sing-box 配置通常分为 inbounds、outbounds、route 和 dns。修改前保留原文件备份，并使用客户端内置校验功能检查 JSON 语法。

{
  "log": { "level": "info" },
  "route": { "auto_detect_interface": true }
}

不要把访问令牌、订阅 URL 或私钥提交到公开仓库。出现连接异常时，先查看日志中的 DNS、TLS 和路由决策，再逐项缩小范围。
